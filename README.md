# What is this?

There's a public domain book published in 1993 called "Seed Germination Theory
& Practice". It's been floating around a bit, but it's a low quality B&W scan.

The goal of this project is to reformat and fix the LaTeX to best match this book.

The book is interesting as it documents ways of germinating many species.

However, I wouldn't use this as a primary source on propagation protocols. Some
of the data doesn't really match propagation protocols as given by, say RGNR.
In particular the use of GA-3 is probably over-promoted. For example, *Ribes
cereum* doesn't really require it, simple tumbling or sanding should work.

But this document is an intersting historical reference and some of the protocols
still seem worth trying. (If you're interested in cold stratification using
artificial means, there's a good bit of advice, for example.)

As book was never professionally type-set, it seemed worthwhile to give it a go.

Example scan: https://www.gardenmyths.com/wp-content/uploads/2018/06/Deno-Seed-Germination-First-Suplement-min.pdf

# Project Principles

- Retain (or recreate) the original text, tables, diagrams, figures, etc.
- Improve readability

Things that I feel are allowed:
- Formatting changes: Spacing, text emphasis, adding sub-sections. (Things
like underlying should be italics.)
- Re-order things to make it look more like an actual book

Things considered:
- There are species or genera name changes. Maybe adding footnotes would help
modern readers identify species.
- Italicize species names. (I don't think the original author would like this,
however.)
