[Seed Germination Theory & Practice](seed-germination-theory.pdf)

# What is this book about?

*Seed Germination Theory & Practice* is a book from the US Forest Service
(in the public domain) published in 1993
containing information on how to germinate various species' seeds.
It's been floating around online, but it's only available as a low quality,
black and white scan, and is difficult to read and use.

The goal of this project is to reformat and fix the LaTeX to best present this book.

The book is interesting as it documents ways of germinating many species.

However, I wouldn't use this as a primary source on propagation protocols. Some
of the data doesn't really match propagation protocols as given by
[USDA's Plant Guide](https://plants.usda.gov/DocumentLibrary/plantguide/), or sources like
[RGNR](https://rngr.net).

In particular the suggested ("required") use of GA-3 is probably over-promoted.'
For example, *Ribes cereum* doesn't really require it, although the author insists, as simple 
[tumbling or sanding](https://npn.rngr.net/renderNPNProtocolDetails?selectedProtocolIds=grossulariaceae-ribes-418)
seems to work.

But this document is an interesting historical reference and some of the protocols
still seem worth trying. (If you're interested in cold stratification using
refrigeration, there's a good bit of advice on preparing seed lots, for example.)

As book was never professionally type-set, it seemed worthwhile to give it a go.

Example scan: https://www.gardenmyths.com/wp-content/uploads/2018/06/Deno-Seed-Germination-First-Suplement-min.pdf

# Project Principles

- Retain (or recreate) the original text, tables, diagrams, figures, etc.
- Improve readability.
- "Undo" incorrect scanning mistakes, such as stray punctuation, wrong letters, etc.

Things that I feel are allowed:
- Formatting changes: Spacing, text emphasis, adding sub-sections. (Things
like underlined text really should be italics in modern printing.)
- Things to make it look more like an actual book, like sections and a proper
table of contents, etc.

Things considered for future work:
- There are species or genera name changes. Maybe adding footnotes would help
modern readers identify species.
- Italicize species names. (I don't think the original author would like this,
however it makes it easier to read in my opinion.)
